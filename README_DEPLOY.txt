БЫТБЛОК — версия для GitHub Pages

Все изображения встроены непосредственно в HTML-страницы.
Это позволяет показывать сайт даже если GitHub не загрузил папку images.

1. Откройте GitHub → репозиторий bytblock → Add file → Upload files.
2. Распакуйте этот ZIP и загрузите 21 HTML-файл из корня.
3. Нажмите Commit changes. Дождитесь завершения Pages deployment.
4. Откройте https://ahatsmmalin-ai.github.io/bytblock/

Это версия для демонстрации. Для продакшена и SEO лучше хранить картинки
отдельными файлами для кэширования и более быстрой загрузки.
